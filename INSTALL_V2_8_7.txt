Clasvanta v2.8.7 — Accounts Permissions, Student Editing & Fine Relief
=======================================================================

LOCAL / FILEZILLA PATCH — nothing is pushed to GitHub.

WHAT THIS PATCH ADDS

1. Accounts staff
- Adds an Accounts application role linked to the Django Group named Accounts.
- Advanced Administration → Users → Add user now exposes Groups.
- Assigning Group = Accounts synchronizes the user to the Accounts role.
- Accounts users are kept out of Django Advanced Administration (is_staff=False).
- Main-site access:
  • Enrolled students
  • Student attendance
  • Add student
  • Edit student details
  • Fines
  • Student fine ledger/history
  • Print challan
- No student deletion.
- No academic setup, lecturer management, attendance management, reports, settings,
  bulk imports, activity administration, or Advanced Administration.
- Fine access is read-only for Accounts users.

2. Fine concession / waiver — Super Admin only
- Partial concession per subject.
- Waive all current outstanding fines for one student.
- Reason is required.
- Original fine charges are never deleted.
- Concession/waiver entries remain in the append-only ledger with actor + timestamp.
- Relief reversal protection prevents later attendance corrections from turning relief
  into a credit against future fines.

3. Student father name and editing
- Optional Father name field.
- Add Student supports Father name.
- Enrolled Students and Student Attendance searches include Father name.
- Fines search includes Father name.
- Edit Student supports:
  • registration/login ID
  • student name
  • father name
- Edit Student does not change class enrollment, attendance, or fine history.

INSTALL WITH FILEZILLA

IMPORTANT: upload BOTH:
- apply_patch.py
- payload/ folder

Keep the folder structure exactly as extracted.

1. Keep your normal attendance_app backup.
2. Extract this ZIP on your computer.
3. Upload apply_patch.py and the complete payload folder into attendance_app/
   beside manage.py.
4. SSH:

   cd /path/to/attendance_app
   source .venv/bin/activate
   python apply_patch.py
   python manage.py check
   python manage.py makemigrations --check --dry-run
   python manage.py migrate
   python manage.py collectstatic --noinput

5. Restart the Python application from Plesk.
6. Hard refresh with Ctrl+F5.

CREATE AN ACCOUNTS USER

Super Admin:
Advanced administration
→ Users
→ Add user
→ enter username/password/name
→ Group = Accounts
→ Save

The application role is synchronized automatically.

SUPER ADMIN FINE RELIEF

Fines
→ View ledger

For partial concession:
- enter amount beside a subject
- enter reason
- Apply concession

For full current waiver:
- enter reason under “Waive all current outstanding fines”
- confirm

BACKUP / ROLLBACK

apply_patch.py creates:
.accounts_permissions_v287_backup_YYYYMMDD_HHMMSS

For code rollback, restore from that directory.

Because this patch includes database migrations, back up the database before deployment.
If you deliberately need a full DB rollback:

python manage.py migrate accounts 0002_user_must_change_password
python manage.py migrate academics 0006
python manage.py migrate fines 0001

Then restore code from the backup.
